# Quality Bar — 6축 명제 + AGENTS.md directive

본 문서는 검증 관점과 severity 경계만 정의한다. wiki 필드·page type·section·taxonomy 값은 각각 `_meta/knowledge.schema.json`과 `_meta/taxonomy.md`가 소유하며 여기에서 복제하지 않는다.

## 등급별 적용 매트릭스

| 축 | raw·authored | canonical wiki | owner |
|---|---|---|---|
| 1. 정확도 | legacy curated raw의 원출처 필드; authored는 사람 원문 | artifact manifest `source_paths`와 Claims evidence | raw lint / canonical checker |
| 2. 전문성 | 자동 판정 없음 | schema section contract + 사람 semantic review | schema / 사람 |
| 3. 일관성 | 원본 vocab 보존 | canonical taxonomy; alias MEDIUM, unknown HIGH | `VR-KP-023` |
| 4. 논리성 | 자동 판정 없음 | Claims evidence verdict + 사람 review | semantic review |
| 5. 정합성 | broken link·directive | graph·relation·lifecycle·generated parity | raw lint / canonical checker |
| 6. 재현성·시의성 | legacy curated raw recency | immutable artifact digest·manifest·replay identity | raw lint / canonical checker |

## 축 1 — 정확도

- wiki page의 `source_paths`는 하나 이상의 immutable artifact manifest를 가리켜야 한다.
- Claim evidence는 해당 page가 선언한 `source_paths`에 포함돼야 한다.
- raw·wiki 원문에 없는 의미 추론은 자동 구조 검증으로 사실성 PASS를 만들지 않으며 사람 semantic review 대상으로 남긴다.

## 축 2 — 전문성

- wiki 구조는 `_meta/knowledge.schema.json`의 page-type section contract로 HIGH 검증한다.
- 내용의 전문성·설명 품질은 구조 결과와 분리한 사람 review 대상이다.

## 축 3 — 일관성

- canonical tag·entity는 `_meta/taxonomy.md`에 한 번만 정의한다.
- canonical 사용은 PASS, alias 사용은 canonical 대체값을 포함한 MEDIUM, 미등록 값은 HIGH다.
- alias는 자동 치환하지 않으며 canonical 작성값으로 교정한 뒤 저장한다.

## 축 4 — 논리성

- page 간 또는 page 내부의 의미 모순은 구조 checker PASS로 치환하지 않는다.
- primary claim마다 `support`, `contradiction`, `insufficient` 중 하나의 evidence verdict를 기록한다.
- `claimed`·`insufficient` primary claim은 promote할 수 없고, 보존이 필요한 충돌은 Claims와 Open Questions에 명시한다.

## 축 5 — 정합성

- canonical checker는 전역 stable ID·link·relation·collection·lifecycle·directed cycle을 검사한다.
- backlink와 inverse relation은 outgoing edge에서 계산하며 persistent index를 만들지 않는다.
- materializer는 active page coverage와 generated bytes parity를 독립 검증한다.

## 축 6 — 재현성·시의성

- content-addressed artifact는 manifest의 exact digest·size·path를 검증한다.
- 같은 input tuple의 canonical render·materialize 결과는 같은 tree digest를 가져야 한다.
- legacy curated raw Markdown의 `last_verified` 누락은 HIGH다. age 180일 이상은 MEDIUM, 730일 이상은 HIGH이며 raw에는 evergreen 면제가 없다. non-raw authored concept의 명시적 `evergreen: true`만 730일 HIGH를 면제하고 180일 MEDIUM은 유지한다.

## AGENTS.md directive

- `cs/`, `development/`, `coding-test/`, `lang/`, `tools/`는 LLM read-only다.
- raw artifact는 append-only이고 canonical wiki write는 승인된 page/materialize command만 수행한다.
- 페이지 본문의 모델명 grep은 ADR-0001에 따라 사용하지 않으며 taxonomy가 entity vocabulary를 소유한다.

## 판정과 사람 게이트

- `HIGH ≥1`이면 structural verdict는 FAIL이다.
- MEDIUM과 자동 판정 불가능한 의미 품질은 보고하지만 단독으로 structural verdict를 실패시키지 않는다.
- 구조 PASS는 사실성·완전성 PASS가 아니다.
- 사람 review는 PR, promote, claim conflict 해소, taxonomy supersede 시점에 수행한다.
