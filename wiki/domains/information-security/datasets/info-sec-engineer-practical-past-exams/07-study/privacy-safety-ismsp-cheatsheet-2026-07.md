# 개인정보보호법·안전성 확보조치·ISMS-P 조건-기간-대상-조치 암기표

## 기준
2026년 7월 시험 대비는 원칙적으로 시험일 현재 시행 중인 법령과 고시를 기준으로 공부한다.

다만 과거 PDF와 기출 복원에는 구 기준 숫자가 남아 있다. 따라서 답안은 현행 기준으로 잡고, 구 기준은 오답 유발 포인트로만 관리한다.

## 전체 흐름
개인정보와 ISMS-P는 따로 외우지 말고 아래 흐름으로 묶는다.

```text
수집 -> 이용·제공 -> 보관·접근 -> 로그·점검 -> 유출 대응 -> 파기
```

이 흐름에 안전성 확보조치와 ISMS-P를 끼워 넣으면 된다.

| 흐름 | 개인정보보호법 관점 | 안전성 확보조치 관점 | ISMS-P 관점 |
|---|---|---|---|
| 수집 | 처리 근거, 최소수집, 민감정보, 고유식별정보 | 내부관리계획 | 개인정보 처리 단계별 요구사항 |
| 이용·제공 | 제3자 제공, 위탁, 처리방침 | 관리·감독 | 정책, 조직, 준거성 |
| 보관·접근 | 보유기간, 권리보장 | 접근권한, 접근통제, 암호화 | 접근통제, 암호통제 |
| 로그·점검 | 침해 예방 | 접속기록, 점검, 위변조 방지 | 로그 및 모니터링 |
| 유출 대응 | 통지·신고 | 사고 대응 절차 | 침해사고 대응 |
| 파기 | 보유기간 만료 시 파기 | 파기 및 출력·복사물 관리 | 개인정보 생명주기 통제 |

## 시험 판단 원칙
1. 문제에 별도 기준일이 없으면 시험일 현재 시행 중인 법령·고시 기준으로 답한다.
2. 기출 PDF의 숫자와 현행 조문이 다르면 현행 조문을 우선한다.
3. 단, 과거 기출 빈칸을 그대로 묻는 문항에서는 구 기준 정답이 남아 있을 수 있으므로 함정표를 같이 본다.
4. 과태료 금액보다 조건, 기간, 대상, 조치가 훨씬 중요하다.

## A4 핵심 암기
| 묶음 | 반드시 외울 것 |
|---|---|
| 유출 | 통지 72시간, 신고 72시간, 신고처 개인정보보호위원회 또는 KISA |
| 신고 조건 | 1천 명 이상, 민감정보·고유식별정보, 외부 불법 접근 |
| 접근권한 | 부여·변경·말소 기록 3년, 업무 변경 시 지체 없이 변경·말소 |
| 접속기록 | 원칙 1년, 5만 명·민감정보·고유식별정보·기간통신사업자 2년 |
| 내부관리계획 | 1만 명 미만 소상공인·개인·단체 생략 가능, CPO 연 1회 이상 이행점검 |
| 인터넷망 차단 | 일평균 이용자 100만 명 이상, 권한 설정 또는 다운로드·파기 가능 취급자 PC 등 |
| ISMS-P | 3개 영역, 102개 기준 |
| 위험처리 | 수용, 감소, 전가, 회피 |

암기문:

```text
유출은 72, 신고는 1천·민감·고유·외부침입.
권한은 3년, 접속은 1년, 5만·민감·고유·기간통신은 2년.
ISMS-P는 관리체계·보호대책·개인정보 단계, 위험처리는 수감전회.
```

## 1. 수집 단계
| 조건 | 대상 | 조치 | 암기 포인트 |
|---|---|---|---|
| 개인정보 수집 | 정보주체 | 동의 또는 법령상 근거 필요 | 동의, 법령, 계약, 공공, 급박, 정당이익 |
| 민감정보 처리 | 건강, 사상, 생체인식정보 등 | 별도 동의 또는 법령 근거 필요 | 민감정보는 별도 |
| 고유식별정보 처리 | 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호 | 별도 동의 또는 법령 근거 필요 | 고유식별도 별도 |
| 주민등록번호 처리 | 주민등록번호 | 일반 동의만으로 부족, 법령 근거 등 필요 | 주민번호는 더 엄격 |
| 만 14세 미만 아동 | 아동 개인정보 | 법정대리인 동의 | 14세 미만 = 법정대리인 |

## 2. 이용·제공 단계
| 조건 | 대상 | 조치 | 암기 포인트 |
|---|---|---|---|
| 제3자 제공 | 제공받는 외부 제3자 | 제공받는 자, 목적, 항목, 보유기간, 거부권·불이익 고지 후 동의 | 자목항보기거불 |
| 처리 위탁 | 수탁자 | 수탁자와 위탁업무 내용 공개, 관리·감독 | 위탁 = 공개 + 감독 |
| 개인정보처리방침 | 정보주체 | 목적, 항목, 보유기간, 제3자 제공, 위탁, 파기, 권리, 책임자 등 공개 | 전체 공개문서 |

## 3. 보관·접근 단계
| 조건 | 대상 | 기간·기준 | 조치 |
|---|---|---:|---|
| 접근권한 부여·변경·말소 | 개인정보처리시스템 | 3년 이상 | 내역 기록·보관 |
| 업무 변경 | 개인정보취급자 | 지체 없이 | 접근권한 변경 또는 말소 |
| 계정 발급 | 개인정보취급자 | 개인별 | 계정 공유 금지 |
| 내부관리계획 | 개인정보처리자 | 수립·시행 | 보호조직, 교육, 접근권한, 접근통제, 암호화, 접속기록 등 포함 |
| 내부관리계획 생략 가능 | 1만 명 미만 처리 소상공인·개인·단체 | 예외 | 생략 가능 |
| 내부관리계획 이행 점검 | 개인정보 보호책임자 | 연 1회 이상 | 점검·관리 |

암기:

```text
권한 이력 3년.
업무 바뀌면 지체 없이 변경·말소.
계정은 개인별, 공유 금지.
```

## 4. 접속기록·점검 단계
| 조건 | 대상 | 기간·기준 | 조치 |
|---|---|---:|---|
| 개인정보처리시스템 접속기록 | 개인정보처리자 | 1년 이상 | 보관·관리 |
| 5만 명 이상 정보주체 처리 | 해당 시스템 접속기록 | 2년 이상 | 보관·관리 |
| 민감정보 또는 고유식별정보 처리 | 해당 시스템 접속기록 | 2년 이상 | 보관·관리 |
| 기간통신사업자 | 접속기록 | 2년 이상 | 보관·관리 |
| 접속기록 점검 | 개인정보처리자 | 내부관리계획 기준 | 점검 주기·방법·사후조치절차를 정하고 이행 |
| 접속기록 보안 | 접속기록 | 상시 | 위변조, 도난, 분실 방지 조치 |

암기:

```text
접속기록은 1년.
5만·민감·고유·기간통신은 2년.
권한 이력은 3년.
```

## 5. 암호화·접근통제 단계
| 조건 | 대상 | 조치 |
|---|---|---|
| 비밀번호 저장 | 인증정보 | 복호화되지 않도록 일방향 암호화 |
| 인증정보 송수신 | 비밀번호, 생체인식정보 등 | 안전한 암호 알고리즘 적용 |
| 고유식별정보 저장 | 인터넷망, DMZ, 내부망 | 안전한 암호 알고리즘 적용 |
| PC·모바일·보조저장매체 저장 | 이용자 개인정보, 고유식별정보, 생체인식정보 | 암호화 저장 |
| 정보통신망 접근 | 개인정보처리시스템 | IP 제한, 유출 시도 탐지·대응 |
| 외부 접속 | 권한 있는 자 | 인증서, 보안토큰, OTP, VPN 등 안전한 인증·접속수단 |
| 물리적 보관장소 | 전산실, 자료보관실 등 | 출입통제, 잠금장치, 반출입 통제 |

## 6. 유출 대응 단계
| 조건 | 대상 | 기간 | 조치 |
|---|---|---:|---|
| 개인정보 유출 등을 알게 됨 | 정보주체 | 72시간 이내 | 통지 |
| 1천 명 이상 유출 | 개인정보보호위원회 또는 KISA | 72시간 이내 | 신고 |
| 민감정보 또는 고유식별정보 유출 | 개인정보보호위원회 또는 KISA | 72시간 이내 | 신고 |
| 외부 불법 접근으로 유출 | 개인정보보호위원회 또는 KISA | 72시간 이내 | 신고 |
| 연락처 불명 등 정당한 사유 | 정보주체 | 30일 이상 | 홈페이지 또는 사업장 게시로 통지 갈음 |

통지 내용 5개:

| 번호 | 통지 내용 |
|---:|---|
| 1 | 유출 등이 된 개인정보의 항목 |
| 2 | 유출 등이 된 시점과 경위 |
| 3 | 피해 최소화를 위해 정보주체가 할 수 있는 방법 |
| 4 | 개인정보처리자의 대응조치 및 피해 구제절차 |
| 5 | 신고 등을 접수할 담당부서 및 연락처 |

암기:

```text
통지 = 정보주체 = 72시간.
신고 = 개인정보위 또는 KISA = 72시간.
신고 조건 = 1천 명, 민감·고유, 외부 불법 접근.
```

## 7. 영상정보처리기기
| 조건 | 대상 | 조치 |
|---|---|---|
| 공개된 장소에 고정형 영상정보처리기기 설치 | 방문자·정보주체 | 안내판 설치 |
| 안내판 내용 | 촬영 대상자 | 설치 목적·장소, 촬영 범위·시간, 관리책임자 연락처 등 표시 |
| 출입 통제·보호구역 | 시설·장비 | 보호구역 지정, 출입권한 관리, 출입기록 관리 |

## 8. ISMS-P
| 구분 | 내용 |
|---|---|
| 전체 구조 | 3개 영역, 102개 기준 |
| 1영역 | 관리체계 수립 및 운영 |
| 2영역 | 보호대책 요구사항 |
| 3영역 | 개인정보 처리 단계별 요구사항 |

ISMS-P는 아래처럼 개인정보 흐름과 연결해서 외운다.

| 흐름 | ISMS-P 연결 |
|---|---|
| 정책·조직 | 정보보호 및 개인정보보호 정책, 책임자, 조직 |
| 자산·위험 | 정보자산 식별, 중요도 산정, 위험평가 |
| 접근통제 | 사용자 등록·해지, 권한 최소화, 특권계정 통제 |
| 암호통제 | 암호정책, 키 관리, 안전한 알고리즘 |
| 로그·모니터링 | 로그 수집, 보관, 검토, 이상행위 대응 |
| 물리보안 | 보호구역, 출입통제, 정보시스템 보호, 반출입 통제 |
| 개인정보 단계 | 수집, 보유, 이용·제공, 위탁, 파기 |

위험처리 4종:

| 위험처리 | 의미 | 예시 |
|---|---|---|
| 수용 | 위험을 받아들이고 감수 | 낮은 위험을 경영진 승인 후 관리 |
| 감소 | 보호대책으로 위험 수준을 낮춤 | 접근통제, 암호화, 로그 점검 |
| 전가 | 손실 부담을 제3자에게 이전 | 보험, 외주, 계약 |
| 회피 | 위험 행위 자체를 중단·변경 | 위험한 서비스 중단 |

암기:

```text
ISMS-P = 관리체계 / 보호대책 / 개인정보 처리단계.
위험처리 = 수용 / 감소 / 전가 / 회피.
```

## 9. 구 기준·오답 유발 포인트
| 헷갈리는 표현 | 현재 공부 기준 | 설명 |
|---|---|---|
| 정보주체 통지 5일 | 72시간 | 유출 통지·신고는 현행 72시간 기준으로 학습 |
| 기관 신고 1천 명 이상만 | 1천 명, 민감·고유, 외부 불법 접근 | 신고 조건이 1천 명만은 아님 |
| 수사기관 신고 | 개인정보보호위원회 또는 KISA | 수사기관 신고는 범죄 대응상 별도 가능하지만 개인정보보호법상 유출 신고처는 아님 |
| 접속기록 2년은 100만 명 이상 | 5만 명 이상, 민감·고유, 기간통신사업자 | 100만 명은 다른 통제항목과 섞인 숫자 |
| 접속기록 월 1회 점검 | 내부관리계획에 주기·방법·사후조치절차를 정하고 이행 | 과거 기출 빈칸에는 월 1회가 남아 있을 수 있음 |
| 과태료 금액 암기 | 후순위 | 조건·기간·대상·조치가 우선 |

## 10. 시험장 답안 템플릿
법규형 문제는 아래 문장 구조로 답한다.

```text
조건: 어떤 상황에서 의무가 발생하는가.
대상: 누구에게 적용되는가.
기간: 언제까지 해야 하는가.
조치: 무엇을 해야 하는가.
근거 키워드: 통지, 신고, 보관, 점검, 공개, 동의, 암호화, 접근통제.
```

예시:

```text
개인정보 유출 등을 알게 된 개인정보처리자는 72시간 이내에 정보주체에게 유출 항목, 시점·경위, 피해 최소화 방법, 대응조치, 담당부서 연락처를 통지해야 한다.
1천 명 이상, 민감정보 또는 고유식별정보 유출, 외부 불법 접근에 의한 유출인 경우 개인정보보호위원회 또는 한국인터넷진흥원에 72시간 이내 신고해야 한다.
```
