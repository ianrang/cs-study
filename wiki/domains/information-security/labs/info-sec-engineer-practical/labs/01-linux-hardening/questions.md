# Questions

1. In `.sandbox/etc/passwd`, why is the password field `x`?
2. In `.sandbox/etc/shadow`, what do `$6$` and `$5$` indicate?
3. Which source IP should be treated as suspicious in `.sandbox/var/log/auth.log`, and why?
4. Explain the security meaning of SUID, SGID, sticky bit, and world-writable permission using `.sandbox/files/permission-listing.txt`.
5. Write a three-part answer for a Linux account/log inspection question using `evidence -> meaning -> action`.
