# 실기 답안 템플릿

기본 구조:

`무엇인가 -> 왜 문제인가/왜 필요한가 -> 어떻게 설정·탐지·대응하는가`

## 유형별
| 유형 | 구조 |
|---|---|
| 개념형 | 정의 -> 목적 -> 구성요소/예시 |
| 공격형 | 공격명 -> 판단근거 -> 대응방안 |
| 설정형 | 설정값/파일 -> 보안 의미 -> 권장 조치 |
| 로그형 | 로그 필드/증거 -> 의심 행위 -> 확인·차단·보존 |
| 법규형 | 적용 주체 -> 의무/요건 -> 기록·보관·통지·점검 |
| 비교형 | 비교 대상 -> 차이 기준 -> 적용 상황 |

## 오답 분류
| 원인 | 조치 |
|---|---|
| 개념부족 | 정의를 3줄로 다시 쓴다. |
| 키워드누락 | 파일명, 명령어, 설정값, 법규 용어를 암기표에 추가한다. |
| 문장화실패 | 3단 템플릿으로 다시 작성한다. |
| 레퍼런스미확인 | 공식·준공식 레퍼런스 상태를 확인한다. |
| 실습이해부족 | Lab 기대 관찰값을 다시 보고 답안을 보정한다. |
