# Information Security Hands-on Labs

This directory is separate from `datasets/` by design.

- `datasets/` stores reconstructed past exams, analysis, references, and study strategy.
- `labs/` stores reusable study exercises and isolated runnable sandboxes.

Do not place exam reconstructions or reference registries here. Do not place generated lab artifacts in `datasets/`.
