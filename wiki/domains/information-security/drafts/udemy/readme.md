# Udemy 정보보안기사 학습 노트 Draft 인덱스

### 목적

### 원칙
- 이 폴더의 문서는 공식 기출 복원 SSOT가 아니다.
- 이 폴더의 문서는 공식 레퍼런스 교차검증 전까지 `datasets/info-sec-engineer-practical-past-exams/` 분석 근거로 직접 사용하지 않는다.
- 정식 승격이 필요하면 회차, 문항 ID, 공식 레퍼런스, 현재 법령·고시 기준을 확인한 뒤 `07-study/` 또는 적절한 책임 그룹으로 재작성한다.
