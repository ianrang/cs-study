### 45. TCP와 UDP를 비교하시오.

TCP와 UDP는 네트워크 OSI 7계층에서 4계층인 전송 계층에 위치한 프로콜입니다. TCP는 연결지향성, 신뢰성을 기반으로 네트워크 통신을 수행하며, 3 way handshake 기반으로 호스트간의 상호 연결을 수행합니다. 그리고 재전송이나 순서를 기반으로 전송합니니다. 단점으로는 해더의 크기가 UDP 보다 크고, 속도가 느립니다.
UDP는 비연결지향성, 비신뢰성을 기반으로 네트워크 통신을 수행하며, 순서를 보장하지 않고 오류 제어나 흐름 제어 기능을 수행하지 않습니다. 하지만 속도가 TCP 보다 빠르며, 신뢰성이 보장되지는 않지만 빠르게 데이터를 전송하거나 실시간성이 필요할 때 사용합니다.

TCP: 스트림 단위, 신뢰성, 순서 보장, 연결성
UDP: 블록 단위, 비신뢰성, 비연결성, 오류제어와 흐름제어 기능 없음

### 47. 어느 계층에 대한 설명인가?

```
- 종단-대-종단에 대한 흐름제어를 제공한다.
- 메시지 분할 및 조립, 순서화, 포트주소 지정, 연결제어, 다중화와 역 다중화 등의 기능을 수행한다.
- 양 끝단(End to End)의 사용자들이 신뢰성 있는 데이터를 주고받을 수 있도록 함으로써 상위 계층들이 데이터 전달의 유효성이나 효율성을 신경 쓰지 않게 해주는 계층이다.
```

### 58. ARP/RARP의 개념 및 동작원리에 대해 서술하시오.

- ARP (Address Resolution Protocol)
  IP 주소를 MAC 주소로 변환하는 작업으로 송신자는 연결하고자 하는 수신자의 MAC 주소를 알지 못할 때 ARP 질의를 브로드캐스팅을 수행한다.
- RARP (Reverse Address Resolution Protocol)
  MAC 주소를 IP 주소로 변환하는 프로토콜이다.

### 59. ARP는 목적지의 IP주소를 이용하여 물리적 주소를 얻는 역할을 한다. ARP는 물리적 주소를 얻기 위해 IP 주소가 속한 네트워크에서 어떠한 주소로 물리적 주소를 요청한다.

FF-FF-FF-FF-FF-FF 또는 브로드캐스트 주소
