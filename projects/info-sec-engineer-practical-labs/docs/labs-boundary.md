# Information Security Hands-on Labs

This project is separate from the canonical past-exam dataset by design.

- The canonical past-exam dataset stores reconstructed exams, analysis, references, and study strategy.
- The local `labs/` directory stores reusable study exercises and isolated runnable sandboxes.

Do not place exam reconstructions or reference registries here. Do not place generated lab artifacts in the canonical past-exam dataset.

Start with the [project README](../README.md).
