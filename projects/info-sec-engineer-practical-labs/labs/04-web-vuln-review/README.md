# Lab 04. Web Vulnerability Review

## Objective
웹 취약점 샘플 코드와 HTTP 요청을 보고 취약점명, 판단근거, 대응방안을 작성한다.

## Exam Pattern
- SQL Injection and PreparedStatement
- Stored/reflected XSS
- CSRF token and Referer/Origin
- SSRF allowlist
- File upload bypass
- CRLF / response splitting

## Run
```bash
sh ./run.sh
```
