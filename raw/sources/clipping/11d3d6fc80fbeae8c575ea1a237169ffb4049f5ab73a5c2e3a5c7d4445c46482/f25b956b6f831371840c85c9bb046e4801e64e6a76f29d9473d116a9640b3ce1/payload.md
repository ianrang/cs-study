### 9. 블록 암호 공격에 관한 내용이다. 빈 칸을 채우시오.

(A) 1990년 Biham과 Shamir에 의해 개발된 선택된 평문 공격 기법으로, 두개의 평문 블럭의 비트의 차이에 대해 대응되는 암호문 블록들의 비트의 차이를 이용하여 사용된 암호열쇠를 찾아내는 방법이다.
(B) 1993년 Matsui에 의해 개발되어 알려진 평문 공격 방법으로, 알고리즘 내부의 비선형 구조를 적당히 선형화시켜 열쇠를 찾는 방법이다.
(C) 1977년 Diffiedhk Hellman이 제안한 방법으로 암호화할 때 일어날 수 있는 모든 가능한 경우에 대해 조사하는 방법으로 경우의 수가 적을 때는 가장 정확한 방법이지만, 일반적으로 경우의 수가 많은 경우에는 실현이 불가능한 방법이다.
(D) 암호문에 대한 평문의 각 단어의 빈도에 관한 자료를 포함하는 지금까지 알려진 모든 통계적인 자료를 이용하여 해독하는 방법이다.
(E) 통계적인 방법을 포함하여, 수학적 이론을 이용하여 해독하는 방법이다.

- 블록 암호 공격 방법에는 차분 공격, 선형 공격, 무차별 공격, 통계적 분석, 수학적 분석
- 차분 공격: 선택된 평문 공격법으로 2개의 평문 블록들의 비트 차이에 대하여 대응되는 암호문 블록들의 비트 차이를 이용하여 사용된 암호열쇠를 찾는다.
- 선형 공격: 평문 공격 기법으로 알고리즘 내부의 비선형 구조를 적당히 선형화시켜 열쇠를 찾는다.
- 무차별 공격: 암호화할 때 이러날 수 있는 모든 가능한 경우에 대해 전수 조사하는 방법으로 경우의 수가 적을 때 유용하지만, 경우의 수가 많을 경우 실현이 불가능하다.
- 통계적 분석: 암호문에 대한 평문의 각 단어의 빈도에 대한 지금까지 알려진 모든 통계적인 자료를 이용하여 해독하는 방법이다.
- 수학적 분석: 통계적인 방법을 포함하여 수학적 이론을 이용하여 해독하는 방법이다.

### 18. 대칭키 암호 방식과 공개키 암호방식을 비교하시오.

대칭키 암호 방식은 암호화키와 복호화 키가 같고 암복호화 속도가 빠르며, 대용량 데이터 암호화에 유리하다. 단점으로는 키 관리가 어렵다.
공캐키 암호 방식은 암호화 키와 복호화 키가 다르고, 키관리 개수가 대칭키에 비해 적다.
그리고 인증, 부인방지 기능을 제공하며, 전자 서명에 주로 사용된다. 단점으로는 연산 속도가 느리고, 암호화 할 수 있는 평문의 길이에 제한이 있다.

==> 대칭키와 공개키의 키 수 학습 필요
대칭키: n(n-1) / 2
공개키: 2n

### 23. 다음 문제의 괄호 안에 알맞은 단어나 기호를 넣으시오.

RSA 알고리즘 공개키와 개인키 생성 순서
1단계 : 두 소수 p, q를 선정한다.
2단계 : n = p × q 를 계산한다.
3단계 : ф(n) = (p – 1) × (q - 1) 을 계산한다.

1. MAC(Mandatory Access Control)

- 강제적 접근 제어
- 각 주체가 각 객체에 접근할 때마다 관리자에 의해 사전에 규정된 규칙과 비교하여 그 규칙을 만족하는 주체에게 접근 구너한을 부여하는 방법이다.
- 정보마다 보안 등급이 정해지며 보안 레이블을 사용한다.
- 보안 등급이 낮은 사용자가 보안 등급이 높은 객체를 읽을 수 없고, 보안 등급이 높은 사용자가 보안 등급이 낮은 객체를 쓸 수 없다.
- BLP 모델을 근간으로 하고 군대, 비밀유출방지에 중점으로 사용됨
- No Read Up, No Wirte Down
- 보안 레이블: 정보 시스템 내에 어떤 객체에 대해 필요한 보안 수준을 나타내는 정보, 강제적 접근 통제 규칙을 적용하기 위한 기반이 된다.

2. DAC(Discretionary Access Control)

- 임의적 접근 통제
- 정보의 소유자가 제어 접근을 설정함
- 리눅스/유닉스 접근 권한 방식에 적용되었음
- ID 도용이나 트로이목마 공격에 취약하다.
- 중앙 집중형 방식이 아닌 객체 소유자의 임의적 판단으로 이루어진다.

3. RBAC (Role Based Access Control)

- 역할 기반 접근 통제
- 조직에서 직무의 권한이나 등급을 부여해서 접근을 제어하는 방식
- 업무에 필요한 권한만 부여하고 직무가 빈번히 변경되는 환경에 적합한 접근 통제 모델이다.

4. Biba

- 무결성을 위한 상업용 모델로 BLP를 보완한 최초의 수학적 무결성 모델이다.

5. Chinese Wall

- 상업적 기밀성, 금융, 회계

6. Clark-Wilson

- 한 사람이 모든 권한을 갖는 것을 방지하고, 각 권한을 여러 사람으로 나눠서 부분적으로 관리하는 무결성을 보장하는 접근 제어 모델이다.

### 41. 다음에서 설명하고 있는 통제를 기술하시오.

( A )는 오류나 부정이 발생하는 것을 예방할 목적으로 행사하는 통제이다. 발생 가능한 잠재적인 문제들을 식별하여 사전에 대처하는 능동적인 개념의 통제이며, ( B ), ( C ) 등으로 나눌 수 있다. 물리적 접근통제란 관계자 이외의 사람이 특정 시설이나 설비에 접근할 수 없게 하는 각종의 통제를 뜻하며, 논리적 접근 통제란 승인을 받지 못한 사람이 정보통신망을 통하여 자산에 대한 접근을 막기 위한 통제 방법이다.

- 예방 통제
  - 물리적 접근 통제
  - 논리적 접근 통제

- 탐지 통제

- 교정 통제
  탐지된 위협과 취약점에 대응하는 것으로 위협과 취약점을 감소
