# 2026년 제1회 정보보안기사 필기 복원문제 정리본

> 원본 HTML의 `문항 / 문제 / 답 / 수제비` 테이블을 기준으로 추출했습니다. 정답은 별도 파일에 분리했습니다.
> 원문이 비어 있거나 일부만 남은 문항은 `[확인 필요]`, `[원문 누락]`, `[원문 불완전]`으로 표시했습니다.
> 저작권 보호를 위해 원문 복원 목적의 최소 정리본이며, 불완전 문항은 임의로 보기를 창작하지 않았습니다.

## 검수 기준

- **원문 답안**: HTML의 답 칸에 정답이 명시된 경우
- **개념상 보완**: 원문 정답은 없으나 정보보안기사 필기 범위의 안정적인 개념으로 보완 가능한 경우
- **원문 불완전 / 원문 누락**: 문제·보기·정답 일부 또는 전체가 없어 확정할 수 없는 경우
