**복원 상태:** CBT 후보 보강
**참고:** 1과목 운영체제/파일시스템 범위

리눅스 파일 시스템의 특징 연결로 가장 옳은 것은?

1. ext2 - 저널링을 기본 제공하며 ext4보다 나중에 등장한 파일 시스템이다.
2. ext3 - 저널링을 지원하며 ext2와의 호환성을 고려해 발전한 파일 시스템이다.
3. FAT32 - POSIX 권한과 소유권 모델을 리눅스 기본 파일시스템처럼 완전하게 제공한다.
4. NTFS - 리눅스 커널의 기본 루트 파일시스템으로 설계된 ext 계열 파일 시스템이다.

### 6. 좀비 프로세스 처리

좀비 프로세스에 대한 설명으로 가장 옳은 것은?

1. 좀비 프로세스 자체에 `kill -9`를 보내면 부모 프로세스의 회수 동작 없이도 즉시 완전히 제거된다.
2. 부모 프로세스가 종료 상태를 회수하지 않아 생기며, 부모 프로세스가 `wait()` 계열 호출로 회수하면 해소될 수 있다.
3. 고아 프로세스와 동일하므로 init/systemd에 입양되면 반드시 좀비 상태로 고정된다.
4. 네트워크 소켓이 열려 있을 때만 발생하며 부모 프로세스의 종료 상태 회수와는 관계가 없다.

<summary>정답 보기</summary>

**정답**: 2

**검수 상태**: CBT 후보 보강

4. FAT32와 동일하게 파일별 ACL 기반 보안 권한을 제공하지 않는 구조로만 동작한다.

**정답**: 4

**검수 상태**: CBT 후보 보강

### 11. SSL/TLS Handshake

**복원 상태:** CBT 후보 보강
**참고:** cs/information-security/02.network-security/07.security-protocols.md

TLS Handshake 과정과 메시지의 연결로 가장 옳은 것은?

1. ClientHello - 클라이언트가 지원 TLS 버전, 암호 스위트, 난수 등을 제시한다.
2. ServerHello - 서버가 클라이언트 인증서 폐지 목록만 배포하고 암호 스위트 협상은 하지 않는다.
3. Certificate - 서버가 세션 키를 인증서에 담아 평문으로 전달하는 단계이다.
4. Finished - 핸드셰이크 검증 없이 평문 세션 키를 그대로 전송하는 단계이다.

<details>
<summary>정답 보기</summary>

**정답**: 1

**검수 상태**: CBT 후보 보강

**검수 메모**: ClientHello에는 클라이언트 지원 버전, 암호 스위트, 난수 등이 포함된다. TLS Handshake는 협상, 인증서 검증, 키 합의, Finished 검증으로 보안 채널을 수립한다.

</details>

IPSec 구성요소와 기능의 연결로 가장 옳은 것은?

1. AH - 페이로드 암호화를 통해 기밀성을 제공하는 것이 주목적이다.
2. ESP - 기밀성, 무결성, 인증 기능을 제공할 수 있으며 전송/터널 모드에서 사용된다.
3. IKE - POP3 메일 다운로드 정책을 설정하기 위한 응용 계층 프로토콜이다.
4. SPD - 전자서명 인증서 폐지 목록을 배포하는 웹 서버 로그 형식이다.

<details>
<summary>정답 보기</summary>

**정답**: 2

**검수 상태**: CBT 후보 보강

**검수 메모**: ESP는 암호화와 인증 기능을 제공할 수 있다. AH는 인증·무결성 중심이고 기밀성은 제공하지 않는다. IKE는 키 교환, SPD/SAD는 보안 정책·SA 관리와 연결된다.

</details>

SDN(Software Defined Networking)에 대한 설명으로 옳지 않은 것은?

1. 제어 평면과 데이터 평면을 논리적으로 분리한다.

4. SDN에서는 제어 평면이 데이터 평면에 완전히 내장되어야 하므로 컨트롤러 기반 중앙 정책 적용이 불가능하다.

<details>
<summary>정답 보기</summary>

**정답**: 4

**검수 상태**: CBT 후보 보강

**검수 메모**: SDN은 제어 평면과 데이터 평면 분리, 컨트롤러 중심 정책 제어, southbound/northbound 인터페이스 개념과 연결된다. 컨트롤러가 핵심 제어 지점이 되므로 보호가 중요하다.

</details>

### 15. NAT 종류 매핑

**복원 상태:** CBT 후보 보강
**참고:** cs/information-security/02.network-security/02.network-protocols-and-addressing.md

NAT 종류와 특징의 연결로 옳지 않은 것은?

1. Static NAT - 내부 사설 IP와 공인 IP를 고정적으로 1:1 매핑한다.
