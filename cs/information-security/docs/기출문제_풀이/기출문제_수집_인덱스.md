# 정보보안기사 필기 CBT/개정 이후 기출 수집 인덱스

> 기준일: 2026-05-11
> 원칙: 공식 공개 기출이 아닌 자료는 "복원/후기 기반"으로 표시한다. 문제 전문은 원 출처 링크에서 확인하고, 이 문서는 회차별 출처 추적용으로 사용한다.

## 판정 기준

- **문제 원문 확보**: 문제와 보기까지 공개 웹에서 확인 가능
- **문제 정리 확보**: 문제 번호별 주제/정답/해설은 있으나 보기 전체는 없음
- **풀이 스크립트 확보**: 강의·영상 스크립트에서 일부 문제와 정답 흐름은 확인되나, 전체 선지 복원은 불완전
- **후기/키워드만 확보**: 응시자가 기억나는 키워드만 제공
- **교재 수록만 확인**: 공개 웹 원문은 없고 교재 목차상 수록만 확인

## 현재 미확정 항목

- 후기가 아닌 "문제 원문 + 보기" 기준으로 공개 확보된 회차는 현재 2023년 1회, 2023년 2회, 2023년 4회다.
- 2023년 3회 필기는 별도 회차 원문을 확인하지 못했다. 공개 검색 결과는 대부분 2023년 1회(2023-03-11)를 잘못 가리킨다.
- Baba Yetu 직접 PDF 링크는 KakaoCDN 서명 URL이므로 만료될 수 있다. 장기 보관 기준 링크는 각 Baba Yetu 포스트 URL을 우선한다.
- 2024년 3월, 2024년 9월, 2025년 6월은 교재 목차상 최신 기출 수록이 확인되지만, 공개 웹에서 문제 전문이 안정적으로 확인되는 출처는 제한적이다.
- 2026년 1회는 시험 후기와 일정은 확인되지만, 공개 복원 문제 원문은 아직 확인하지 못했다.
- 정보보안기사 필기 CBT 이후 자료는 공식 공개 기출이 아니라 응시자 복원/후기/교재 수록 형태가 섞이므로, 출처 신뢰도를 함께 기록해야 한다.
