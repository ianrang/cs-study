# 정보보안기사 학습 경로

## 1회차 핵심 학습 순서

1. `01.system-security/` — 운영체제와 시스템 보안
2. `02.network-security/` — 네트워크와 보안 프로토콜
3. `03.application-security/` — DNS·웹·DB·전자상거래 보안
4. `04.security-general/` — 암호 알고리즘 → 해시/MAC → 키 분배 → 디지털서명/PKI → 인증·접근통제
5. `05.management-and-law/` — 관리체계·사고 대응·인증·법규

각 단원은 선수지식만 직접 참조한다. 세부 단원 목록은 각 과목의 `README.md`를 기준으로 탐색한다.
